# 🍍 Nil Frutas – Cocos Secos e Ralado

Site institucional desenvolvido para a loja **Nil Frutas**, especializada na comercialização de frutas e produtos hortifruti, com destaque para cocos secos e ralados.

O projeto foi criado com o objetivo de atender a uma proposta acadêmica, utilizando **HTML, CSS e JavaScript puros**, sem o uso de plataformas prontas ou frameworks.

---

## 📌 Funcionalidades do Site

- Página inicial com apresentação da loja
- Página “Sobre a Empresa”
- Catálogo de produtos organizados por categorias
- Carrinho de compras simples
- Definição de quantidade por produto
- Remoção de itens do carrinho
- Cálculo automático do total (frete fixo de R$ 5,00)
- Envio do pedido diretamente para o WhatsApp do estabelecimento
- Página de contato
- Página de perguntas frequentes (FAQ)

---

## 🛒 Carrinho de Compras

O carrinho permite:

- Adicionar produtos
- Definir quantidade
- Remover itens
- Informar dados para entrega:
  - Nome
  - Bairro
  - Rua
  - Número
  - Ponto de referência

Ao finalizar o pedido, o sistema gera automaticamente uma mensagem e redireciona para o **WhatsApp da loja**, contendo:
- Lista de produtos
- Quantidades
- Valor total
- Frete
- Endereço de entrega

---

## 🧰 Tecnologias Utilizadas

- **HTML5** – Estrutura das páginas
- **CSS3** – Estilização e layout
- **JavaScript** – Lógica do carrinho e integração com WhatsApp
